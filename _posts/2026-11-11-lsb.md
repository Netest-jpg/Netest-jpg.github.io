Got curious on how hackers embed secret messages inside medias like images, videos and audio files and found out about steganography. I am going to implement one by myself to understand the schema.
Steganography is divided into different categories depending on the type of the media you are working with. For example: Image steganography, Audio steganography, Video steganography, etc.
There are various algorithms to implement one. I am going to start with image steganography and the simplest algorithm it has to offer first. Least Significant Bit (LSB) steganography.
LSB steganography works by changing a certain amount of last bits inside the bytes of an image to the bits of the message you want to embed.

(Note: This is simplest form of LSB steganography. You can optimize things to be more secret and faster)

Prerequisite Knowledge:
-  There are different kinds of images. There are raster images, vector images, voxel images and more. But ignore that for now, what we want to focus on are raster images. These are your typical pixelated images where each pixels hold a color.
-  There are also different kind color models. What's a color model you say? You might have heard of RGB. It is a color model. Similarly, there are other models like RGBA, BGR, BGRA, CMYK, OKLCH, etc. These models define how a computer stores the data for an image.
   For example, An RGB image is stored like this:
```txt
   (R, G, B), (R, G, B), (R, G, B),...
```

   All color models can be converted from one to another but whether there is loss of information depends on what color model you are converting from and into. 
   For example:
   Converting a RGBA to RGB means that the alpha channel is discarded and converting a RGB to RGBA cannot magically recreate a color data that was never there to begin with.
   
   Since RGB is the most common color model among raster images, we are going to stick with RGB. We will convert any image given to us and change it's color model to RGB.
   Now, we must choose the bitdepth of the image, A bit depth is essentially the range of numbers a color channel can store. For example, an 8-bit image, can store 0-255 different values. A higher bit means more precision. But for now, we will stick with 8 bit.
   So therefore, RGB8.
   
Algorithm: 
1. We take in a message. Convert that message into bytes.
   For example:
```txt
   "Hello World" -> 01101000 01100101 01101100 01101100 01101111 00100000 01110111 01101111 01110010 01101100 01100100
```

2. I mentioned before that images look like this:
   (R, G, B), (R, G, B), (R, G, B),...
   But in actuality, since our computer only sees in 0s and 1s, it looks more like this:
   (00001111 00001111 00001111), (00001111 00001111 00001111), (00001111 00001111 00001111).
   Now we will take a certain amount of last bits from the each byte. The more bits we take, the higher the payload; meaning more message. But more bits we take, more likelihood of being spotted. For now, let's only take one.
   these are the places we will be changing:
```html
(0000111<mark>1</mark> 0000111<mark>1</mark> 0000111<mark>1</mark>), (0000111<mark>1</mark> 0000111<mark>1</mark> 0000111<mark>1</mark>), (0000111<mark>1</mark> 0000111<mark>1</mark> 0000111<mark>1</mark>)... ... ...
```

4. Now, we take the length of the message and encode that into the image as the first step so that our decoder knows when and where to stop.
   For example: Our message "Hello World" is 11 bytes long. We will take this number as a u32 and divide it into 4 bytes.
   This is what it would look like:
```txt
00000000 00000000 00000000 00001011
```

   We will take each consecutive bits like this:
```html
<mark>0</mark>0000000 00000000 00000000 00001011
```

   compare them to the place we will be changing:
```html
0000111<mark>1</mark> ... ... ...
```

   if it doesn't match, we change it
```txt
00001110
```

   otherwise, we keep it like that.
5. And finally, we do the same for the message:
```html
<mark>0</mark>1101000 ... ... ...
```

   compare the bit to the place where it is going:
```html
0000111<mark>1</mark> ...
```

   Since they don't match, we change the bit.
```txt
00001111 -> 00001110
```

We do this for all the bits inside the image and after that, we have successfully hidden the message.
Now to get the message, we reverse everything we have done so far. I am not going to bore you with further speech, it is fairly simple and you should probably understand once you see the code.
so here is the full code:
```rust
use image::ImageReader;
use std::error::Error;
use std::io;
use std::str::from_utf8;

fn main() -> Result<(), Box<dyn Error>> {
    // encoding part
    let image = ImageReader::open("Saturn.png")?.decode()?;
    let (width, height) = (image.width(), image.height());
    let mut raw = image.to_rgb8().into_raw();

    let mut input = String::new();
    io::stdin().read_line(&mut input)?;
    let message = input.trim().as_bytes();

    let mut payload = (message.len() as u32).to_be_bytes().to_vec();
    payload.extend_from_slice(message);

    if raw.len() < payload.len() * 8 {
        return Err("Message is too big".into());
    }
    let mut i = 0;
    for byte in payload.iter() {
        for bit in 0..8 {
            let msg_bit = (byte >> (7 - bit)) & 1;
            raw[i] = msg_bit;
            i += 1;
        }
    }

    image::save_buffer("out.png", &raw, width, height, image::ColorType::Rgb8)?;

    // decoding part
    let altered = ImageReader::open("out.png")?.decode()?;
    let raw = altered.to_rgb8().into_raw();
    let last_bits: Vec<u8> = raw[..32].iter().map(|&x| x & 1).collect();
    let mut result = [0u8; 4];
    for (chunk_idx, chunk) in last_bits.as_chunks::<8>().0.iter().enumerate() {
        let mut byte = 0u8;
        for (bit_idx, &value) in chunk.iter().enumerate() {
            byte |= (value & 1) << (7 - bit_idx);
        }
        result[chunk_idx] = byte;
    }
    let length = u32::from_be_bytes(result);
    if raw.len() < (32 + (length * 8)) as usize {
        return Err("Index out of bounds".into());
    }
    let lsb: Vec<u8> = raw[32..(32 + (length * 8) as usize)]
        .iter()
        .map(|&x| x & 1)
        .collect();
    let mut result: Vec<u8> = Vec::with_capacity(length as usize);
    for chunk in lsb.as_chunks::<8>().0 {
        let mut byte = 0u8;
        for (bit_idx, &value) in chunk.iter().enumerate() {
            byte |= (value & 1) << (7 - bit_idx);
        }
        result.push(byte);
    }
    let msg = from_utf8(&result)?;
    println!("message: {}", msg);
    Ok(())
}
```
(Note: The code is not fully optimized for secrecy and speed. It is solely for learning purposes)
